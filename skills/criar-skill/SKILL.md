# Criar uma skill

## Entrada
- Tarefa: {TAREFA}
- Tempo que leva hoje: {TEMPO}

## Passos
1. Escreva em uma frase quando a skill deve ser usada.
2. Liste os passos, na ordem, com o que entra e o que sai de cada um.
3. Liste as regras que não podem ser quebradas.
4. Inclua um exemplo de entrega pronta.
5. Depois de usar 3 vezes, compare o tempo com o de antes. Se não economizou, ajuste ou descarte.

## Formato da resposta
Um arquivo `SKILL.md` completo, com `name` e `description` no topo.
